# Minimap Marker Assets

Cara pakai di Unity:
1. Import PNG ke folder Assets/UI/Minimap.
2. Klik PNG, set Texture Type = Sprite (2D and UI).
3. Klik Apply.
4. Pilih Canvas > Border > PlayerMarker.
5. Pada Image > Source Image, masukkan salah satu marker PNG.
6. Atur Width dan Height sekitar 12-20 untuk minimap kecil.
